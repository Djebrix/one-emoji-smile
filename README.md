One emoji, chosen to make a stranger smile: a face visibly moved, grateful, and about to smile — warmth at first glance, no words needed. See the competition at https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f.

## Run

```sh
python3 main.py
```

This writes the single emoji to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
